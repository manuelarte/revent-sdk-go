# R-Event SDK Go

> [!WARNING]
> R-Event-SDK-Go is under heavy development.

SDK to interact with [R-Event][revent] for the Go programming language.

## Getting Started

To add the SDK to your project, run the following command:

```bash
go get github.com/manuelarte/revent-sdk-go
```

[revent]: https://github.com/manuelarte/revent
